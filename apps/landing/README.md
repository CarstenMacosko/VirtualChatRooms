# Landing page

A static page about VirtualChatRooms: plain HTML and CSS in `public/`, with no build step and no dependencies, so it deploys anywhere.

**Cloudflare Pages settings**

| Setting                | Value          |
| ---------------------- | -------------- |
| Root directory         | `apps/landing` |
| Framework preset       | None           |
| Build command          | _(empty)_      |
| Build output directory | `public`       |

Preview locally by opening `public/index.html` in a browser, or with `npx serve apps/landing/public`.
